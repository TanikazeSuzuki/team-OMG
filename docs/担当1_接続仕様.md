# 担当1 接続仕様

他担当は、認証・ユーザー・設定に関してこの仕様を利用してください。担当1の所有ファイルを直接変更する必要がある場合は、変更前に担当1へ依頼してください。

## ユーザー参照

モデルでは直接`accounts.User`を外部キーへ指定せず、次を利用します。

```python
from django.conf import settings
from django.db import models

user = models.ForeignKey(settings.AUTH_USER_MODEL, on_delete=models.CASCADE)
```

実行時にユーザーモデルを取得する場合は次を利用します。

```python
from django.contrib.auth import get_user_model

User = get_user_model()
```

## ユーザー種別と権限

| 判定 | 利用方法 |
|---|---|
| 一般参加者 | `user.role == User.Role.PARTICIPANT` |
| 主催者 | `user.role == User.Role.ORGANIZER` |
| 主催者または管理者 | `user.is_organizer` |
| Django管理者 | `user.is_staff` |

クラスベースビューで主催者権限を必須にする場合は、`accounts.permissions.OrganizerRequiredMixin`を利用します。

## ユーザー設定

| データ | 利用方法 |
|---|---|
| 希望地域 | `user.preference.desired_location` |
| 通知可否 | `user.preference.notifications_enabled` |
| テーマ | `user.preference.theme_color` |

ユーザー作成時に`UserPreference`も自動作成されます。既存データを安全に扱う処理では`UserPreference.objects.get_or_create(user=user)`を利用できます。

## フォームとテンプレート

| フォーム | テンプレート | 主なフィールド |
|---|---|---|
| `RegistrationForm` | `accounts/signup.html` | `email`, `name`, `role`, `password1`, `password2` |
| Django `AuthenticationForm` | `accounts/login.html` | `username`（画面上はメールアドレス）, `password` |
| `ProfileForm` | `accounts/profile.html` | `email`, `name` |
| `UserPreferenceForm` | `accounts/preferences.html` | `desired_location`, `notifications_enabled`, `theme_color` |
| `AccountDeletionForm` | `accounts/delete_confirm.html` | `password`, `confirmation` |

フォーム送信にはCSRFトークンを含めてください。ログアウトと退会は状態を変更するため、POSTで実行してください。
